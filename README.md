# Hi, I'm Samzong (船长) 👋

## What I build

- **Agent Harnesses**: Supervision for coding agents, with parallel sessions, teams, artifacts, approval gates, and scheduled tasks.
- **Agentic Developer Workflows**: Worktrees, session history, Agent Skills, and review gates for daily development.
- **Native macOS Tools**: Terminals, launchers, editors, and utilities that I use in my own workflow.
- **Inference Serving Stack**: Scheduling and routing for heterogeneous models, vLLM, and llm-d on Kubernetes.
- **Kubernetes-Native Workloads**: Batch queueing, multi-cluster scheduling, and GPU sharing for AI/ML workloads.
