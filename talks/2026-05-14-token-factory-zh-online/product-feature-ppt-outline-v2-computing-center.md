# Token Factory 产品功能增强版 PPT 大纲 v2：面向智算中心

> 状态：v2 讨论稿  
> 用途：产研团队提供给市场团队的智算中心产品力素材母稿  
> 关系：基于 v1 产品功能增强版拆分；本版本只服务智算中心，不混讲企业内部平台  
> 建议页数：34 页素材页，市场团队可裁剪为 25-30 页销售版  
> 读者：市场团队、售前团队、销售团队、产品与研发团队  
> 叙事规则：先结果，后论证  
> 边界：本文是素材母稿，不是最终 PPT、不写官网完整文案、不做视觉设计

## 0. 核心判断

面向智算中心的产品介绍，必须先给出产品能带来的经营结果，再展开产品能力。Token Factory 的产品力不是功能多，而是能把 GPU / NPU / DCU、模型、推理、计量、客户、账单、SLA、FinOps、安全和电力约束组织成一套可经营的 Token 工厂。

# 第一章：智算中心可获得的结果

## P01｜结果总览：GPU 资产变成可售 Token 产能

- 主对象：C 智算中心管理层
- 产品力表达：Token Factory 把资源、模型、推理、计量和经营组织成 Token 工厂。
- 结果指标：可售 Token 产能、单位 Token 成本、SLA、收入、毛利、资产回本、客户增长。
- 能力论证：MaaS 出口负责交付，后台负责治理，Dashboard 负责经营可见，Copilot 负责分析建议，InferX 负责生产优化。
- 视觉建议：资源 -> Token 产能 -> 客户 / 收入 / 毛利的链路图。
- 素材来源：`HARD_GATES.md`、`dashboard-html-materials.md`
- Gate：不能写成模型 API 商店。

## P02｜结果指标：吞吐、成本、SLA 和毛利的 Without / With 对比

- 主对象：C 管理层 / C 财务
- 产品力表达：产品价值可用经营指标量化，不停留在“平台能力”。
- 结果指标：吞吐 +50.6%，单位 Token 成本 -29.1%，SLA 95.2% -> 99.7%，日均毛利 +62.9%。
- 能力论证：集中调度、KV Cache、模型匹配、算电协同、安全网关和预算治理共同产生增益。
- 视觉建议：对比表 + 价值归因瀑布图。
- 素材来源：`dashboard-html-materials.md` 页面 1。
- Gate：数字用于内部素材母稿，公开前确认披露范围。

## P03｜结果指标：单机资产经营和回本期

- 主对象：C 财务 / C 管理层
- 产品力表达：平台能按机器级资产回答“赚不赚钱、多久回本、是否低效”。
- 结果指标：H100 高产资产月收入 ¥3.42M、月毛利 ¥1.74M、回本期 10.7 月；低效资产回本期 52-60 月。
- 能力论证：Token 计量、资源成本、模型/GPU 匹配、折旧和租户收入进入同一资产账本。
- 视觉建议：资产泡泡矩阵。
- 素材来源：`dashboard-html-materials.md` 页面 3。
- Gate：外部公开需匿名化节点与资产细节。

## P04｜结果指标：客户套餐增长和收入机会

- 主对象：C 运营
- 产品力表达：产品不只是提供服务，还能支持客户运营和增长动作。
- 结果指标：47 活跃租户、3.82T 月消费、ARPU ¥18.0K、12 个租户套餐消耗率 >90%、星辰科技升级预计月增收 ¥45K。
- 能力论证：租户、套餐、用量、模型、GPU 和账单在 Dashboard 中联动；Copilot 生成升级建议。
- 视觉建议：租户象限 + 升级机会卡。
- 素材来源：`dashboard-html-materials.md` 页面 2。
- Gate：不要把它写成普通 CRM。

## P05｜结果指标：算电协同释放产能和降低成本

- 主对象：C 运维 / C 财务
- 产品力表达：智算中心特有的电力约束进入 Token 经营系统。
- 结果指标：功率约束下额定产能 1.72M tok/s -> 2.10M tok/s，新增额定产能 +8.3%，月节省电费 ¥38.2K。
- 能力论证：功率、水位、电价、PUE、绿电、碳账户和业务优先级联动调度。
- 视觉建议：功率水位策略表。
- 素材来源：`dashboard-html-materials.md` 页面 7。
- Gate：算电协同不是 ESG 装饰。

## P06｜结果指标：多租户安全和业务连续性

- 主对象：C 安全 / C 管理层
- 产品力表达：商用 Token 服务必须保护多租户边界和可售产能。
- 结果指标：18.7M 今日请求，风险请求 23,412，拦截率 99.2%，被保护业务 97.8%。
- 能力论证：Prompt 注入、越权访问、恶意工具调用、敏感输出、数据泄漏尝试和多租户越界进入治理闭环。
- 视觉建议：安全风险漏斗。
- 素材来源：`dashboard-html-materials.md` 页面 4。
- Gate：公开材料谨慎使用具体风险对象。
