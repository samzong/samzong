# 第二章：为什么企业需要统一 Token 供给平台

P06

分散 AI 调用会带来成本、SLA 和安全失控

先结果Gate
C 管理层 / C 平台方问题定义

如果继续让部门各自接模型和 API，企业会失去统一成本、SLA 和安全边界。

论证：分散调用的问题不是工具多少，而是组织级治理缺失。

  • 多部门各自采购模型 API 或自建服务。
  • 应用 / Agent 缺少统一鉴权、配额、审计和成本归因。
  • 管理层无法判断哪些 AI 使用产生业务价值。
