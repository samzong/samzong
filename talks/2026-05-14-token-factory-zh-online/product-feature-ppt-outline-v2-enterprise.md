# Token Factory 产品功能增强版 PPT 大纲 v2：面向企业用户

> 状态：v2 讨论稿  
> 用途：产研团队提供给市场团队的企业内部 MaaS / Token 供给产品力素材母稿  
> 关系：基于 v1 产品功能增强版拆分；本版本只服务大型企业内部平台，不混讲智算中心对外经营  
> 建议页数：32 页素材页，市场团队可裁剪为 22-28 页销售版  
> 读者：市场团队、售前团队、销售团队、产品与研发团队  
> 叙事规则：先结果，后论证  
> 边界：企业用户指 C 类大型企业内部 AI / IT / 平台方，兼顾 B 类部门和业务管理者，不是 A 类个人终端用户

## 0. 核心判断

面向企业用户的产品介绍，必须先给出内部治理和业务结果，再展开产品能力。Token Factory 在企业内部场景中的价值不是“卖 Token”，而是建设统一、可治理、可预算、可审计、可保障的内部 AI 供给平台。

- 销售 PPT：优先使用 P01-P06、P07-P10、P12-P16、P18-P21、P23-P26、P27-P31。

# 第一章：企业内部可获得的结果

## P01｜结果总览：统一内部 AI 供给，替代分散调用

- 主对象：C 企业 AI / IT 平台方
- 产品力表达：Token Factory 帮企业建立统一内部 MaaS / Token 供给平台。
- 结果指标：统一模型服务、统一 API、统一预算、统一 SLA、统一审计。
- 能力论证：MaaS 出口、管理后台、AI 网关、Dashboard、Copilot、推理生产底座协同。
- 视觉建议：分散调用 -> 统一供给平台。
- 素材来源：`HARD_GATES.md`
- Gate：企业版不是 ToC API 商店。

## P02｜结果指标：部门、应用和 Agent 的 Token 用量可统计

- 主对象：C 平台方 / B 管理者
- 产品力表达：企业内部 AI 使用对象可以被统一度量。
- 结果指标：23 个活跃部门、156 个应用 / Agent、Agent 68、App 88。
- 能力论证：Dashboard 按部门、应用、Agent、Workflow、Copilot 和知识助手统计。
- 视觉建议：部门 / 应用 / Agent 统计卡。
- 素材来源：`dashboard-html-materials.md` 页面 1 / 2。
- Gate：不要把 B 类内部治理写成 A 类个人体验。

## P03｜结果指标：预算可控，成本可分摊

- 主对象：C FinOps / B 管理者
- 产品力表达：内部 AI 成本进入 Showback / Chargeback 和预算治理。
- 结果指标：月分摊成本 ¥523.8K，预算使用率 72.4%，Showback 覆盖率 91.3%，单位业务成本 ¥4.11/M Token。
- 能力论证：Token 计量、部门归属、应用归属、模型成本和资源成本统一。
- 视觉建议：预算和分摊仪表。
- 素材来源：`dashboard-html-materials.md` 页面 2。
- Gate：Chargeback 是内部成本分摊，不是对外计费。

## P04｜结果指标：关键业务 SLA 可保障

- 主对象：C 平台方 / B 业务负责人
- 产品力表达：关键业务可以被优先保障，非关键流量可以被治理。
- 结果指标：关键业务保障率 99.5%，SLA 99.93% 场景样例。
- 能力论证：AI 网关、配额预算、路由策略、容量预测和 Copilot SLA 分析协同。
- 视觉建议：关键业务保障策略图。
- 素材来源：`dashboard-html-materials.md`、`copilot-html-materials.md`
- Gate：不要承诺所有请求都高优先级。

## P05｜结果指标：内部 AI 使用价值可证明

- 主对象：C 管理层 / B 业务管理者
- 产品力表达：平台不只看成本，也能证明业务收益。
- 结果指标：客服中心 Copilot 业务价值评分 A+，月均节省人工成本约 ¥180K。
- 能力论证：业务使用、Token 消费、成本分摊和业务价值评分连接。
- 视觉建议：业务价值卡片。
- 素材来源：`dashboard-html-materials.md` 页面 2。
- Gate：不要只讲节省成本，也要讲治理和可持续供给。

## P06｜结果指标：安全、权限和审计闭环

- 主对象：C 安全 / C 平台方
- 产品力表达：企业内部 AI 使用可以符合权限、安全和审计要求。
- 结果指标：风险请求 23,412，拦截率 99.2%，安全事件闭环率 85.7%。
- 能力论证：Prompt 注入、越权访问、恶意工具调用、敏感输出和多租户越界进入治理。
- 视觉建议：安全治理漏斗。
- 素材来源：`dashboard-html-materials.md` 页面 4。
- Gate：安全不是附加模块。
