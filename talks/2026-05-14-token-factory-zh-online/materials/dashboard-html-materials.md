# Token Factory Dashboard HTML 素材封存

来源：`token-factory/dashboard/token-factory-dashboard.html`

用途：封存老板 HTML 原型里的 Dashboard 能力、页面结构、指标口径、示例数据和经营建议。本文不保留 CSS / DOM / JS 实现细节，只保留后续 PPT、官网、销售话术、产品讨论真正可复用的内容。

## 一句话定位

Dashboard 在老板原型里不是单纯监控页，而是 `DaoCloud Token Factory 经营驾驶系统`：把 GPU、模型、Token、租户、部门、成本、电力、安全和财务指标放到一个经营视角里，让 C 类客户看到“资源如何变成可交付、可计量、可盈利、可持续运营的 Token 产能”。

## 信息架构

顶部导航包含 7 个主要入口，HTML 内另有独立的模型与 GPU 协同页：

- 经营价值
- 业务经营
- FinOps / 财务
- 安全防护
- 生产运营
- 资源成本
- 算电协同
- 模型与 GPU 协同

全局交互：

- 固定顶部导航，当前页面高亮。
- 页面级筛选：时间范围、集群、模型、区域、SLA 基线等。
- 实时刷新：关键 KPI 约每 3 秒轻微波动，表达“实时经营驾驶舱”。
- Tab：经营价值有“公众服务经营版 / 企业内部经营版”；业务经营有“租户与客户经营版 / 部门与应用经营版”；生产运营内也有“实时监控 / 模型 × GPU 协同”。
- 视觉表达：深色经营驾驶舱，KPI 卡片、趋势图、排行、热力矩阵、资产矩阵、Sankey、Waterfall、Gauge、预测置信带、建议区。

- 全部在线 GPU 卡的算力被实际用于 Token 推理生产的平均比例。

- 经营含义：利用率越高，GPU 投入越充分转化为可交付 Token 产出。
- 反向指标：空转率 6.8%，错配率 4.2%。
- 优化目标：通过模型-GPU 最优匹配、智能调度填充空闲时段，降低单位 Token 成本并提高毛利。
